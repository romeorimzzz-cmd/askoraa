ASKORAA FINAL V1 — SETUP

1. ZIP ko project folder me extract karo aur existing app source ko is pack se replace karo. `.git`, `.env.local`, node_modules aur .next ko delete mat karo.

2. Netlify Environment Variables me EXACTLY ye 2 keys rakho:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY

NEXT_PUBLIC_SUPABASE_ANON_KEY ki zarurat nahi hai.

3. Supabase SQL Editor:
- Fresh project: pehle supabase/schema.sql run karo.
- Tumhara existing project: supabase/migrations/20260818_askoraa_final_v1.sql run karo.

4. Migration ke baad Git push karo. Netlify npm run build chalayega.

5. Public pages bina login: Home, Solve Problems, Post detail, Solved Archive, Safety, Terms, Support.
Login required: post, I CAN HELP, accept, Solve Room, chat, rating, profile/my.

6. Main flow:
Post Problem -> I CAN HELP -> Notification -> Accept & Solve -> private room -> chat -> final solution -> YES/NO -> rating/archive.

7. NO ke baad owner Solve Room ko reopen kar sakta hai. YES ke baad room solved archive me preserve hota hai.

8. Safety: OTP/password/UPI PIN/card details/remote access code kabhi share mat karo.
