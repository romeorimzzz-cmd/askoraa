ASKORAA V1 — SIMPLE SETUP

Bhai, is ZIP ko chalane ke liye ye steps follow karo.

1) SUPABASE BANAO
- supabase.com kholo
- New Project
- Project banne do

2) DATABASE LAGAO
- Supabase ke SQL Editor me jao
- ZIP ke andar supabase/schema.sql kholo
- Pura code copy karo
- SQL Editor me paste karo
- Run dabao
- Error aaye to screenshot bhejo; guess se change mat karna.

3) KEYS LO
Supabase ke API/settings section se:
- Project URL
- Publishable/anon client key

4) LOCAL COMPUTER PAR
Node.js LTS install karo.

Project folder me terminal kholo:

npm install

Phir:

npm run dev

Browser:
http://localhost:3000

5) TEST
Do accounts banao:
A = problem owner
B = solver

A:
- Login
- ASK post

B:
- Login
- Home
- I CAN HELP

A:
- Post kholo
- B ko solver select karo
- Room kholo

A + B:
- Chat karo
- Page refresh karke dekho history hai
- YES/NO test karo
- Rating test karo

6) VERCEL PAR LIVE
- Project GitHub par upload karo
- vercel.com kholo
- New Project
- GitHub repo import karo
- Environment Variables me:
  NEXT_PUBLIC_SUPABASE_URL
  NEXT_PUBLIC_SUPABASE_ANON_KEY
- Deploy

7) IMPORTANT
Supabase secret/service-role key ko kabhi frontend me mat dalna.
